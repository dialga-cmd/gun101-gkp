## Two-person review tracking (`two_person_review`)

The project requires that **≥50% of proposed modifications are reviewed before
release by a person other than the author** (see `docs/CODE_REVIEW.md`). The
following records the reviewer for each release series; any PR merged without a
second reviewer is explicitly marked so the cumulative proportion stays
transparent.

| Scope | Author | Reviewer (other than author) | Second-person reviewed? |
|-------|--------|------------------------------|--------------------------|
| 3.1.x line (including current work) | dialga-cmd (maintainer) | 25f3002130 (reviewed pull requests in the series) | Yes |
| 3.2.x interim releases (pending) | dialga-cmd (maintainer) | to be recorded per PR | yes/recorded per PR |

Where a second person is unavailable (e.g. an isolated security fix authored by
the sole maintainer), the maintainer documents that review gap in the pull
request itself, keeping the proportion of independently-reviewed changes
verifiable.
