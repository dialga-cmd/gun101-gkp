# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.1.1] - 2026-08-09

### Changed

- **Error‑message oracle fix**: Decryption error messages are now fully generic across all failure paths, including malformed protocol and version headers. All validation and decryption errors raise `ValueError("Decryption failed")`; only malformed JSON/UTF‑8 raises `ValueError("Invalid container format")`. This prevents an attacker from distinguishing failure reasons via error messages.

- **RSA public exponent whitelist narrowed**: The accepted public exponents are now limited to `3` and `65537`. Exponent `17` has been removed because it cannot be generated by this library’s own key‑generation routine and there is no real‑world interoperability requirement for it.

- **Test reliability improved**: Fixed a probabilistic failure in the exponent validation test by implementing a retry loop that ensures generated test keys have a public exponent coprime with φ(p,q), making the test deterministic.

### Fixed

- Various internal test adjustments to align with the updated error‑message handling (tamper‑detection tests now expect the generic `"Decryption failed"` message).

- Updated `.gitignore` to properly ignore build artifacts, editor directories, and other development-only files.
